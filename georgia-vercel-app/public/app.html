Connect your workbook.

This private website previews the interface. Live records run in your own Google Apps Script web app.

  1. Download the setup package below and unzip it.
  2. Open your workbook. Choose Extensions, then Apps Script. Keep your existing Main file.
  3. Add a script file named SupportApp. Paste SupportApp.gs into it. Add an HTML file named SupportApp and paste SupportApp.html into it.
  4. The existing project already has a doGet function. Follow SETUP.txt to route app requests without breaking note links.
  5. Deploy a new web app. Execute as yourself and restrict access to Only myself. Open the deployment URL with ?app=support.

The app reads current records. Editing and existing automation remain available through links to the original sheets. It does not mark invoices paid or claimed.
